# 関数説明書

## 概要
`utils.py` はよく使うユーティリティ関数をまとめたモジュールです。

---

## 関数一覧

### `calculate_area(width, height)`

- **説明**：長方形の面積を計算する
- **引数**：
  - `width`：長方形の幅
  - `height`：長方形の高さ
- **戻り値**：幅と高さを掛け算した面積
- **使用例**：
  ```python
  calculate_area(10, 20)  # → 200
  ```

---

### `format_price(price)`

- **説明**：価格を通貨形式にフォーマット
- **引数**：
  - `price`：フォーマットしたい数値
- **戻り値**：3桁ごとにカンマを入れて円記号を付けた文字列
- **使用例**：
  ```python
  format_price(98000)  # → ¥98,000
  ```

---

## メイン処理

スクリプトとして直接実行した場合（`__name__ == "__main__"`）、`calculate_area(10, 20)` をテスト実行して結果を出力します。
